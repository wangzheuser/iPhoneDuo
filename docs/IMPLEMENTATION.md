## 本次验证

- Python：204 项测试通过，新增定时购买自动确认、金额上限和无副作用重试判定。
- Rust：20 项本地 Web 共享引擎测试通过，新增一次性计划持久化、同账号重复计划限制、worker 重试元数据和安全重试执行验证；桌面 crate 仍需 Rust 1.90 或更新版本。
- Playwright 界面：26 项测试通过，覆盖登录后才完成添加、启动勾选、顺序检查、未勾选账号隔离、取消重试、API 昵称更新、移除失效账号后留在当前页面，以及原有购买与付款交互；新增邮箱默认脱敏、键盘显隐、切换账号恢复隐藏、窄窗口取消位置、减少动画，以及统一下拉菜单的键盘操作和窄窗口定位验证。
- `pnpm dev:web` 实际服务测试：未登录保存通用配置、刷新后读取、新账号继承、DUO 路由、窄屏、HMR 与重启均验证；UI 模拟覆盖 DUO 刷新成功 / 失败、未知与未开放状态，不把测试数据当作实时库存。
- PyInstaller 内置进程通过无网络检查。
- Apple Silicon macOS：生成「DUO Killer」`.app` 和 `local-web-release/`；本轮不生成安装器。界面截图及交互测试统一通过 `pnpm dev:web`。
- 原 Python 项目 Git 工作区保持干净，没有修改旧源码或迁移真实凭据。

## 约束

- 一个真实 Apple 账号只登记一个 profile；不同账号并行，同账号串行。
- 程序只打包一份 Python worker，按任务启动实例；不同账号不设并行数量上限，同账号保留独占执行。
- 用户主动点击才请求 Apple；开发验证使用合成数据与离线测试。
- 保留原 SRP / SSI / authx / Cookie 更新流程，不自动重试下单请求。
- 提交订单前展示服务端返回的商品、数量、总价并要求用户明确确认。
- worker 通过私有管道接收密码/验证码，不通过命令行参数或日志传递。
- CLI 和桌面版分别适配交互；桌面版不解析中文终端输出来驱动业务。
- Windows 构建只能以 Windows CI/实机结果确认；macOS 成功不能代替 Windows 验证。
